# IMV-Modular-Marine-Biomimetic-Platform
CAD models, fabrication drawings, and assembly documentation for a modular biomimetic marine research platform. Includes the Otaria flavescens dummy, articulated joints, rib structures, and elastic connections for passive movement.

Project overview

IMV explores how biological morphology can inform configurable instruments for marine observation and experimentation.
The project originated in a requirement for a physical sea lion representation to support research on predation risk and reef fish behaviour. Its development combines morphological reconstruction, modular construction, digital fabrication, and iterative marine trials.
The platform is being developed towards configurations representing different marine mammals and accommodating research-specific sensor payloads. These extensions remain under development.
